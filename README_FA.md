# شکارچی کد دیجی‌کالا — نسخه ۵

## امکانات
- باز کردن صفحه عمومی مسابقه در WebView (فقط دامنه‌های digikala.com؛ لینک‌های بیرونی مسدود می‌شوند)
- پیمایش صفحه برای بارگذاری تصاویر lazy-load
- جمع‌آوری تصاویر قابل‌مشاهده (`img`، `srcset`، `picture`، `background-image`) تا سقف ۸۰ تصویر جدید در هر صفحه
- OCR با Google ML Kit (روی دستگاه)
- حذف تصاویر تکراری (نسخه‌های مختلف اندازهٔ یک تصویر یکی حساب می‌شوند)
- تشخیص الگوی احتمالی `DK` + ‏۳ تا ۸ نویسه
- اسکن حداکثر ۵ صفحه با لینک «بعدی» قابل‌شناسایی (به‌صورت ترتیبی؛ هر صفحه بعد از پایان OCR صفحهٔ قبل)
- ذخیره تاریخچه کدهای احتمالی روی گوشی؛ دکمه‌های **کپی کدها** و **پاک کردن**
- دکمه توقف واقعاً اسکن را قطع می‌کند؛ دکمه Back در صفحه‌های وب به عقب برمی‌گردد

## تغییرات نسبت به نسخه ۴
- **رفع اجرای هم‌زمان OCR:** قبلاً با رفتن به صفحه بعد، OCR صفحه قبل هنوز در جریان بود و چند اسکن هم‌زمان اجرا می‌شد؛ حالا کل اسکن یک coroutine ترتیبی است.
- **توقف واقعی:** دکمه «توقف» قبلاً OCR را متوقف نمی‌کرد.
- **حذف `JavascriptInterface`:** هر اسکریپت داخل صفحه (مثلاً تبلیغ) می‌توانست پل `Hunter` را صدا بزند. حالا نتیجه با `evaluateJavascript` گرفته می‌شود و هیچ API‌ای به صفحه باز نیست.
- **محدودسازی دامنه:** هم ناوبری و هم دانلود تصویر فقط روی `*.digikala.com` و فقط HTTPS.
- **جلوگیری از کرش حافظه (OOM):** بیت‌مپ‌های بزرگ با `inSampleSize` کوچک می‌شوند و بعد از OCR آزاد (`recycle`) می‌شوند؛ دانلود با سقف ۴MB.
- **رابط کاربری:** اندازه‌ها از پیکسل به dp تبدیل شد (ناحیه نتایج قبلاً روی گوشی‌های امروزی بسیار کوچک بود)، RTL فعال شد و فاصله از نوار وضعیت/ناوبری برای اندروید ۱۵ (targetSdk 35) رعایت می‌شود.
- **ساخت:** `compileOptions`/`jvmTarget` روی ۱۷ تنظیم شد، نسخه Gradle روی ۸.۱۰.۲، اکشن `setup-gradle` روی `v4`، افزودن `timeout` و `concurrency` به workflow و اضافه شدن `.gitignore`.
- README نسخه ۴ «کپی دستی» را ذکر می‌کرد ولی دکمه‌ای برایش نبود؛ اضافه شد.

## ساخت APK
1. Android Studio را نصب و اجرا کن.
2. فایل ZIP را Extract کن و پوشه پروژه را باز کن.
3. صبر کن Gradle Sync کامل شود.
4. از منوی Build گزینه Build APK(s) را بزن.
5. فایل APK در `app/build/outputs/apk/debug/` ساخته می‌شود.

## ساخت خودکار APK در GitHub
1. همه فایل‌ها (از جمله پوشه `.github`) را در شاخه `main` آپلود کن.
2. زبانه **Actions** ← **Build Android APK** ← **Run workflow**.
3. بعد از اتمام، از بخش **Artifacts** فایل `DK-Hunter-debug-APK` را دانلود و ZIP آن را باز کن.

این APK نسخه debug برای آزمایش است، نه نسخه release امضاشده.

## تنظیم الگوی کد
اگر قالب واقعی کدها فرق داشت، فقط `CODE_REGEX` را در `OcrScanner.kt` عوض کن.
OCR گاهی `0/O` و `1/I` را اشتباه می‌خواند؛ کد پیدا‌شده را همیشه خودت در سایت بررسی کن.

## محدودیت‌ها
- این پروژه کامپایل و روی دستگاه تست نشده است؛ ممکن است در اولین Build به اصلاح جزئی نیاز داشته باشد.
- فقط تصاویر عمومی بارگذاری‌شده در صفحه بررسی می‌شوند.
- اسکن چندصفحه‌ای به وجود لینک «بعدی» قابل‌شناسایی وابسته است.
- در صورت HTTP 403 یا 429 (چه برای صفحه، چه برای تصویر) اسکن فوراً متوقف می‌شود.
- با رفتن برنامه به پس‌زمینه اسکن متوقف می‌شود.
- CAPTCHA، ورود و کنترل‌های ضدربات دور زده نمی‌شوند و هیچ کدی خودکار ثبت یا ارسال نمی‌شود.
- استفاده از ابزار خودکار ممکن است با قوانین مسابقه یا شرایط استفاده سایت در تعارض باشد؛ قوانین مسابقه را بررسی کن.
